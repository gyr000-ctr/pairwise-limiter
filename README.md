# pairwise-limiter

## 题面（可直接粘贴）

给解码器增加只解前 N 个样本的提前停止，并保证并发与内存约束。约束：N 小于总数时与完整解码逐样本一致；N 为 0 不得触发任何解码；N 超过总数要报明确错误；停止后同一对象可继续使用且可重复调用；同一对象被两个线程并发调用时结果与串行一致；解码 1000 次后内存不增长；单次调用耗时不得随已解样本数增长。验收：python -m pytest tests -q -k limit。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- N 为 0 返回空
- N 超过总数要报错
- 停止后 reader 可继续使用
- 耗时随 N 近似线性
- 并发调用不得共享可变状态

## 运行方式

```bash
python -m pytest tests -q
```
